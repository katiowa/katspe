# KatsPE - Modular Grand Strategy Map Engine & Editor

KatsPE is an ultra-fast, lightweight, and fully modular map editor built from the ground up for grand strategy developers, scenario designers, and modding communities. Engineered to eliminate the performance bottlenecks and rigidity of legacy tools, KatsPE gives creators complete control over large-scale territorial topologies with uncompromising vector precision.

Available as a native Windows Desktop Executable and standalone Android APK.

---

## What is KatsPE?

KatsPE is a standalone creative suite designed to sculpt, configure, and export grand strategy world maps. It treats game formats as modular plugins rather than hardcoded rules, allowing developers and modders to build custom format pipelines, introduce localized interfaces, and edit complex world borders in real time without lag.

Whether you are building an original grand strategy title, creating vast historical overhauls, or adapting maps across different engines, KatsPE provides a pure, distraction-free environment engineered strictly for productivity.

## Key Highlights

### 1. Ultra-Lightweight & Radically Optimized
- Unrivaled Responsiveness: Designed to sustain a flat 60 to 120 FPS even when rendering and calculating tens of thousands of complex territorial provinces.
- Instant Startup: Zero bloated runtime dependencies. Projects open and save in fractions of a second.
- Minimal Footprint: Optimized for low memory and CPU usage, ensuring high performance on low-end machines and mobile devices without thermal throttling or memory crashes.

### 2. Built for Developers: Total Extensibility
- Custom Converter Ecosystem: Completely decoupled from any single game engine. Developers can write lightweight converter modules to import, parse, and export whatever proprietary map format their game demands.
- Dynamic Localization: Create and drop in new interface translation packs seamlessly, complete with custom UI asset and flag mapping.
- Data-Driven Architecture: Extend tool behaviors and define custom point-of-interest datasets without needing to modify or recompile the core editor.

### 3. Precision Vector Border Manipulation
- Natural Territory Drafting: Draw provinces with intelligent magnetic snapping that locks adjacent borders and eliminates micro-gaps.
- Boolean Merging & Clipping: Merge bordering nations, carve out enclaves, and slice overlapping borders with mathematically robust polygon operations.
- Smart Island Topology: Automatically detect problematic diagonal border links and correct them into clean orthogonal connections to prevent rasterization artifacts.
- X-Ray Diagnostic Mode: Identify unclosed loops, unshared boundaries, and orphaned vertices across the entire world with one click.

### 4. Advanced Reference Alignment
- Reference Props with Perspective Mesh: Overlay historical maps, satellite heightmaps, or concept sketches directly on the workspace.
- Non-Destructive Deformation: Rotate references via precision angle controls, lock aspect ratios, adjust transparency, and warp perspective across a configurable bilinear mesh grid.

### 5. Professional, Fluid Ergonomics
- Fully Dockable Interface: Tailor your workstation on demand. Pin toolbars to screen edges, float inspector panels, or collapse modules to prioritize pure canvas space.
- Floating Quick-Action Hub: An adjustable, scalable shortcut hub that moves and adapts to mouse or touchscreen ergonomics.
- Multi-Domain Undo/Redo: Safe, non-destructive editing with isolated history tracks across province topology, point coordinates, and reference assets.
- Auto-Regenerative Storage: Resilient internal state management that gracefully handles missing or reset configuration trees without crashing.
